Support Policy

For mobile apps, Envato does not offer any support. However, we offer free complimentary technical support for a period of 3 months strictly.

What's Include :
  • Answering technical questions about the features and functionality.
  • Assistance with reported bugs or issues which are in the original source code.
What's NOT Included :
  • Installation service
  • Issues due to code your customization.
  • Server Setup, Local/Online environment issues.
  • Support for Play Store or Apple store rejection points.

Errors

  • Platform Exception

    1. flutter clean
    2. flutter pub get
    3. flutter run

  • Any Package (dependency) Exception

    - Delete pubspec.lock file

    Run Following commands :

    1. flutter clean
    2. flutter pub cache repair
    3. flutter pub get
    4. flutter run
